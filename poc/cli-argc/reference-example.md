# `,case-text`

Convert text to upper or lower case (CLI declaration POC).

## Options

| Flag / option | Description | Required | Default | Choices |
| --- | --- | --- | --- | --- |
| `--case <CASE>` | Convert text to this case | no | lower | lower, upper |
| `-n, --no-newline` | Do not print a trailing newline | no | — | — |
| `-h, --help` | Print help | no | — | — |
| `-V, --version` | Print version | no | — | — |

## Arguments

| Argument | Description | Required | Default | Choices |
| --- | --- | --- | --- | --- |
| `TEXT` | Text to convert | yes | — | — |
