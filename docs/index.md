# Dotfiles

Portable, reviewable setup for **Pop!_OS and macOS**.

- [Get started](getting-started/index.md) — install or update a machine
- [How-to guides](guides/index.md) — manage tools, configuration and development hooks
- [Roadmap](roadmap.md) — implemented capabilities and what comes next
- [Architecture](architecture/index.md) — design choices and security boundaries

The [public repository](https://github.com/daniel-price/dotfiles) contains no private credentials or work-owned configuration. Installing tools or applying configuration requires approval. See [requirements](requirements.md) for the principles behind those safeguards.
