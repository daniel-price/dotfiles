# Repository layout

| Path | Purpose |
| --- | --- |
| `bin/` | User commands |
| `setup/` | Machine setup, update and cleanup |
| `lib/` | Shared runtime helpers |
| `.config/` | Dotfiles |
| `modules/` | Optional capabilities |
| `containers/` | Container definitions |
| `dev/` | Development tooling, tests and generators |
| `docs/` | Documentation |
| `.github/` | CI |
